# Instrumentals — The Heavens Declare

The Heavens Declare 

Instrumentals for Albums 122–124

Fourteen instrumental tracks for Albums 122–124. No vocals. The serpent spoke. Sons of God. One language. The heavens declare. Quiet worship. Open sky, empty wooden cross, open Book. Not a replacement for the vocal albums.
